# Asset Specifications (Class-C — external DCC work)

These assets cannot be binary-generated by a text agent. Each spec is precise enough to hand to
a 3D/anim/VFX/audio artist and get a correct result. The mod **runs without them** (vanilla
fallbacks noted); they are the polish layer (§A.2).

Tooling: Blender + SoulsFormats FLVER import/export (or the FLVER Blender plugin), Substance
Painter/Designer for textures, DSAnimStudio for TAE, `@cccode/fxr` for VFX, a DAW + wwise/fmod
for audio.

---

## 1. Dr. Doom armor (FLVER protector set) (§5)

Replaces a chosen head/body/arms/legs protector slot group (reserved IDs in `params/50`).
Comic-Doom-first silhouette; Elden-Ring adaptation second.

**Model**
- 4 parts: `HD` (masked head + hood), `BD` (armored torso + cloak attach), `AM` (gauntlets),
  `LG` (armored greaves/boots).
- Poly budget (game-safe): head ~8–12k tris, body ~25–35k, arms ~10k, legs ~10k. LOD1 ~50%,
  LOD2 ~25% (ER expects at least LOD0+LOD1; author LOD2 for crowd distance).
- **Iconic elements (must-have):** riveted iron mask with narrow eye slits; green hood framing
  the mask; heavy green hooded cloak; metallic plated torso with subtle tech paneling; armored
  gauntlets with palm dummypoly for energy VFX; regal Latverian collar clasp.
- **Avoid:** MCU redesign language, sci-fi clutter, generic medieval plate, full-surface glow.

**Rig / weighting**
- Weight to the standard ER `c0000` humanoid skeleton (do **not** invent bones). Cloak/cloth
  weighted to available cloak/back bones; test deformation on run/roll/backstep/attack anims.
- Add dummypoly (damipoly) at both palms, chest, and mask-eyes for VFX attach (Doom energy,
  Emperor eye-glow). Note the dummypoly IDs used → they're referenced by FXR spawn events.

**Materials / textures** (per part: albedo, normal, metallic, roughness, AO; ER MATBIN)
- Iron mask/armor: high metallic, mid roughness, subtle scratches; steel-with-warm-tint albedo.
- Green cloak/hood: cloth MATBIN, low metallic; subtle arcane inscription in the normal/emissive
  channel (faint, not full-surface glow).
- Tech paneling: thin emissive lines (green), masked so they read at distance without glowing
  the whole model.
- Equip icons: 4 menu icons (matching ER icon dimensions) + set icon.

**Cloth / cloak physics** — use ER's cloth setup where the base skeleton supports it; otherwise
weight the cloak to bones and accept animated cloth. Test clipping on rolls/teleport (§5).

**Fallback if unmade:** any vanilla heavy set with the P1–P7 SpEffect chain attached; the systems
are identical, only the look differs.

## 2. Mjolnir (FLVER weapon) (§14)

**Model** — short handle, leather-wrapped grip (normal-map weave), wrist strap, rectangular uru
head with engraved Norse/mystic detailing; believable uru metal (high metallic, subtle
iridescence); **restrained** idle glow, runes brighten when powers activate (emissive mask driven
by a "charged" material param / swapped MATBIN, or an FXR overlay keyed to `MODE_MJOLNIR`).
- Poly ~8–15k. Author both the real weapon and an **empty-hand variant** (invisible or bare fist)
  for the throw state (§A.5).
- Do **not** base the whole design on one film; blend comic + Norse myth (§14 objective).
- Weapon dummypoly at head + grip for lightning/throw VFX and the return-catch effect.

**Fallback:** any hammer with the Mjolnir moveset + FXR; empty-hand variant can be an invisible
weapon model.

## 4. Animations (HKX) + TAE (§16/§42)
New/edited clips, imported via ERClipGenerator, evented in DSAnimStudio. Posture = regal,
minimal wasted motion, no acrobatics (§42).

| Set | Clips needed | Notes |
|---|---|---|
| Doom melee | jab-combo(3), backhand, kick-launcher, shockwave-punch(charge), ground-slam, aerial-slam | heavy-fist base; add cancel windows |
| Doom cast | palm-out blast, two-hand beam-channel, gesture-sorcery, shield-raise | clean hand/dummypoly alignment |
| Teleport | short blink (collapse-in/out), directional dash | i-frame windows in TAE |
| Mjolnir melee | R1 chain, overhead smash, sweep, spin, rising, aerial slam, running, charged | camera-shake + debris TAE events on heavies |
| Mjolnir throw | wind-up, throw, empty-hand idle, catch-on-return | drives the §A.5 state machine |
| Transformations | Odinforce raise-to-sky, Infinity multi-burst pose, Emperor levitation/aura | monumental timing |

**TAE event checklist per attack:** hitbox on/off, `SpEffect` inflict, FXR spawn (correct
dummypoly), SFX cue, cancel window, camera-shake (heavies only), invincibility window (dodges/
teleports). **Fallback:** reuse the closest vanilla moveset's TAE and only re-point VFX/SFX.

## 5. VFX (FXR) (§40) — authored via `@cccode/fxr`
Palette + families defined in [`../fxr/palette.md`](../fxr/palette.md); authoring scaffold in
[`../fxr/build_fxr.mjs`](../fxr/build_fxr.mjs). One FXR "family" per source; recolor variants via
ER-SFXRecolorTool for speed. Keep particle counts budgeted (§55): burst-then-clear, no
thousands-of-persistent emitters.

Minimum FXR set (reserved IDs in `params/00`):
`fxr_doom_energy`, `fxr_doom_beam`, `fxr_doom_field_dome`, `fxr_doom_teleport`,
`fxr_doom_electric`, `fxr_sorcery_sigil`, `fxr_mjolnir_shock`, `fxr_mjolnir_throw`,
`fxr_mjolnir_return`, `fxr_bifrost`, `fxr_odin_aura`, `fxr_odin_beam`,
`fxr_stone_{space,mind,reality,power,time,soul}`, `fxr_disintegrate`, `fxr_infinity_sequence`,
`fxr_emperor_aura`.

## 6. Audio (§41)
New SFX bank(s) via the game's audio pipeline (wsi/wem). Families: Doom-tech (electromagnetic
charge, metallic resonance, discharge), Doom-sorcery (occult resonance, whispered textures),
Mjolnir (huge impacts, thunder, electrical crack, rumble), Odinforce (deep celestial swell,
divine impact), Stones (cosmic distortion + per-stone activation tone). Loudness matched, not
just louder-to-mean-powerful (§41). **Fallback:** map to the closest vanilla SFX IDs in TAE
until custom banks exist.
